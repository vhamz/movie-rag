# Conventions

## Границы изменений

- одна итерация - одно изменение, минимальный diff
- KISS: не добавляю абстракции "на будущее"
- не трогаю файлы, не относящиеся к текущей итерации

## Архитектура модулей

- `scripts/` — запускаемые скрипты (prepare_datasets, ingest, build_index, проверки)
- `app/config.py` — все пути и константы в одном месте, никаких magic numbers по коду
- `app/chunker.py` — только нарезка текста, без I/O логики поиска
- `app/retriever.py` — только поиск по индексу
- `app/generator.py` + `app/prompts.py` — сборка ответа и шаблоны
- `app/main.py` — только UI, бизнес-логики нет

Зависимости между модулями в одну сторону: main -> retriever/generator -> config.

## Правила ответа

- ответ строится только из найденных чанков, ничего от себя
- если все score ниже порога, тоотказ фиксированной фразой
- в ответе всегда показываем источники: doc_id, name, score

## Тесты

- на каждый модуль с логикой (chunker, retriever) свой файл тестов
- тесты не зависят от собранного индекса — где надо, строим маленький индекс во временной папке
- перед коммитом итерации: uv run pytest tests/ -v должен быть зеленый
