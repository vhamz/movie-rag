# Идея проекта

## Проблема

Часто помнишь фильм только по куску сюжета ("там мужик застрял во временной петле"),
а название вспомнить не можешь. Гуглить долго, плюс легко словить спойлеры.

## Цель проекта

Сделать поиск по базе кратких сюжетов фильмов: задаешь вопрос на естественном языке,
получаешь подходящие фрагменты сюжетов и ответ со ссылками на источники (doc_id + score).
Если в базе ничего подходящего нет то отказ.

## Для кого проект

- для любителей кино, кто ищет фильм по описанию;
- учебный пример RAG-пайплайна для семинара.

## Какие данные используем

CMU Movie Summary Corpus — открытый корпус сюжетов фильмов из Википедии,
42306 записей (plot_summaries.txt + metadata с названиями фильмов).
В рабочий datasets.json беру выборку 1500 сюжетов. Подробнее в [DATA.md](DATA.md).

## Критерий успеха

- build_index.py собирает индекс по 1500 документам без ошибок
- 3 demo-вопроса находят релевантные фрагменты со score > 0
- negative-вопрос (не про кино) дает отказ
- все тесты зеленые
